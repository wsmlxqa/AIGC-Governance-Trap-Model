# Code and Data for: "Who shirks, who reports, who profits? Unraveling the user-led content governance trap in AI-generated short-video ecosystem"

## 📖 Overview

This repository provides the complete replication package for the manuscript:

**"Who shirks, who reports, who profits? Unraveling the user-led content governance trap in AI-generated short-video ecosystem"**

The study employs a tripartite evolutionary game model and numerical simulations to analyze the user-led content governance trap and the complementary conditions (institutional deterrence and platform verification capacity) required to escape it.

## 🗂️ Repository Structure

```
.
├── Appendix/                # Supplementary materials (Appendix A–E)
├── Code/                    # All simulation and plotting scripts (MATLAB + Python)
├── Data/                    # Raw and processed simulation datasets
├── Figures/                 # Publication-ready high-resolution figures
├── Pseudocode/              # Algorithm workflow documentation
├── Tables/                  # Parameter tables and analysis results
└── README.md
```

### Folder Details

- **`/Appendix/`**: Contains `Appendix_A.pdf` through `Appendix_E.pdf` (stability proofs, payoff derivations, additional robustness checks, etc.).
- **`/Code/`**:  MATLAB scripts (`.m`) and Python scripts (`.py`).
- **`/Data/`**: All raw simulation outputs .
- **`/Figures/`**: Final high-resolution versions of all figures in the manuscript.
- **`/Pseudocode/`**: Formal pseudocode and algorithm description.
- **`/Tables/`**: Parameter calibration tables, Jacobian matrices and analysis results.

## 💻 System Requirements

- **MATLAB** (R2023a or newer recommended) for simulation scripts.
- **Python 3.8+** with packages: `numpy`, `pandas`, `matplotlib`, `scipy` (for Python-based figure generation).
- No specialized MATLAB toolboxes required.

## 🚀 How to Reproduce the Figures

1. Clone or download the repository.
2. Set the `Code/` folder as your working directory in MATLAB (or use Python environment).
